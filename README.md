# hiya! 
Hey, I'm bajtix and I do games, web and basically every other form of software development. I also consider myself an artist and a tinkerer, which you can probably figure out based on my public repos.

## Tech stack preferences
1. lightweight web
	- not a fan of frontend frameworks, although I understand their usage
	- raw html+css go a long way if anyone puts in the time
	- php is often enough
2. free software
	- proprietary technologies are fun to waste your time on but are not reliable
	- that also applies to my Unity games
3. rust and c
	- although rust is probably one of the best low-level languages nowadays, i still do believe the main reason for that is not memory safety but the comfort of a package manager
	- if Cmake was not as quirky and needlessly complex we'd all still be writing everything in good old C
